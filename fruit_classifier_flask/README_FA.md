# پروژه Fruit Classifier با Flask و TensorFlow

این پروژه یک رابط کاربری تیره برای تشخیص سیب و پرتقال دارد. تصویر در مرورگر انتخاب می‌شود، به Flask ارسال می‌شود، در سمت سرور به RGB و اندازه ورودی مدل تبدیل می‌شود و سپس به `model.keras` داده می‌شود.

## ساختار پوشه‌ها

```text
fruit_classifier_flask/
├── app.py
├── model.keras          # فایل مدل خودتان را اینجا قرار دهید
├── requirements.txt
├── README_FA.md
├── templates/
│   └── index.html
└── static/
    ├── style.css
    └── script.js
```

## راه‌اندازی

ابتدا وارد پوشه پروژه شوید و یک محیط مجازی بسازید:

```bash
python -m venv .venv
```

فعال‌سازی در Linux:

```bash
source .venv/bin/activate
```

فعال‌سازی در Windows:

```powershell
.venv\Scripts\activate
```

نصب وابستگی‌ها:

```bash
pip install -r requirements.txt
```

فایل `model.keras` را کنار `app.py` قرار دهید و سپس اجرا کنید:

```bash
python app.py
```

بعد در مرورگر آدرس زیر را باز کنید:

```text
http://127.0.0.1:5000
```

## نکته حیاتی درباره پیش‌پردازش

کد اندازه ورودی مدل را از `model.input_shape` می‌خواند؛ بنابراین اگر مدل با ورودی 224×224 آموزش دیده باشد، همان اندازه استفاده می‌شود و اگر با 128×128 آموزش دیده باشد، همان اندازه.

اما نرمال‌سازی باید دقیقاً با زمان آموزش یکسان باشد:

- اگر در زمان آموزش `image / 255.0` انجام داده‌اید، `NORMALIZE_PIXELS = True` بماند.
- اگر مدل با پیکسل‌های خام 0 تا 255 آموزش دیده، آن را `False` کنید.
- اگر از preprocessing اختصاصی یک معماری مثل EfficientNet یا MobileNet استفاده کرده‌اید، باید همان preprocessing دقیق را در `preprocess_image` پیاده‌سازی کنید.

## ترتیب کلاس‌ها

این کد فرض می‌کند خروجی Softmax دو واحدی مدل به این ترتیب است:

- خروجی شماره 0: Apple
- خروجی شماره 1: Orange

این ترتیب باید با ترتیب برچسب‌ها در زمان آموزش یکسان باشد. اگر ترتیب کلاس‌ها متفاوت باشد، نام و احتمال‌ها اشتباه نمایش داده می‌شوند.

## نکته درباره Confidence

درصد نمایش‌داده‌شده احتمال خروجی مدل است؛ الزاماً به معنی دقت واقعی 98 درصدی مدل نیست. برای ارزیابی واقعی باید مدل روی داده‌های تست مستقل سنجیده شود و در صورت نیاز کالیبراسیون احتمال انجام شود.
